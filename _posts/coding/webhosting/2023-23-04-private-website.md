# Password-protected pages

In order to make your blog or a webpage private, you can set a password protection by adding a `.htaccess` and `.htpasswd` files to your server.

Here is an example of a [htpasswd-generator](https://www.entwicklertools.de/tools/htaccess/htpasswd-generator/)

For more information see [Apache Documentation](https://httpd.apache.org/docs/2.4/howto/htaccess.html)
