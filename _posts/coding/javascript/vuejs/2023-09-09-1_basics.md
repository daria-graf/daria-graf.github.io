## v-bind Directive

```js
<a href="{{ myLink }}">Link to my website</a>
// Will not work. It will be renderd in html as-is unconverted
// The {{}} -syntax is only available between opening and closing html-tags
// The following syntax must be used instead

<a v-bind:href="{{ myLink }}">Link to my website</a>
// A proper value will be set dynamically
```

Shorthands:

`v-bind:href --> :href`

## Event Biding

```js
// Event Binding in Vanilla-JS
// const button = document.querySelector('button');
// button.addEventListener('click', event => {
//   button.textContent = `Click count: ${event.detail}`;
// });
// or by registering an event handler function
// button.onclick = function() { // do something };
// or as a HTML event handler attribute (considered outdated and bad practice)
// <button onclick="alert('Hello');">Press me</button>

<button v-on:click="showMessage()">Click me!</button>
// mouse event 'click', see https://developer.mozilla.org/en-US/docs/Web/API/Element

<input type="text" v-on:input="showInput" value="Type here">
// input event 'input', see https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement
<p>{{inputText}}</p>

<input type="text" v-on:input="showName($event, 'default')" value="Your name">
<p>{{name}}</p>

// app.js
const app = Vue.createApp({
    data(){
        inputText: '',
        name: ''
    },
    methods:{
        showInput(event) {
            this.inputText = event.target.value;
        }
        showName(event, modus){
         if(modus==='default'){
             this.name = event.target.value;
         }
        }
    }
});
```

## Event Modifiers

"It would be better if the methods can be purely about data logic rather than having to deal with DOM event details. To address this problem, Vue provides ¢[event modifiers(external lilnk)](https://vuejs.org/guide/essentials/event-handling.html#multiple-event-handlers){:target="\_blank"}"

```js
// prevent modifier prevents the browser from reloading the page
<form v-on:submit.prevent="submitForm">...</form>

// the event will be triggerd only on the right click
// possible modifiers for the mouse events: right, left, middle
<button v-on:click.right="showMessage()">Click me!</button>

// More than one key events on one element are also possible

// Example for key modifiers
// v-on:keyup.enter
// also possible modifiers: ctrl, shift, page-down etc.


// app.js
const app = Vue.createApp({
    data(){
    },
    methods: {
        submitForm() {
            alert("Form submitted");
        }
    }
});
```

1. Two-way binding = data binding (v-bind:value="myValue") + event binding (e.g. v-on:input="updateMyValue($event)")

2. v-model directive

```js

// is used as a shortcut instead of (on.input + v-bind)
```

## Computed Properties

We should use computed functions, in order to make the html-template easy to read and not overloaded with the complex logic that includes reactive data.

```js
 // Instead of
 <span>{{ user.children.length > 0 ? 'Yes' : 'No' }}</span>

 // use a computed property
 <span>Children: {{hasChildren}}

// app.js
...
computed: {
    // a computed getter
    hasChildren() {
      return this.user.children.length > 0 ? 'Yes' : 'No'
    }
  }
...
```

We should use computed functions instead of methods, because they are cached based on their reactive dependencies. The greeting() function will only be executed, when dependencies like user.username will be changed. Otherwise the previous computed result will be returned without re-evaluating the value. In contrast methods are executed each time a component they are placed in is re-rendered.

```js
// app.js
const app = Vue.createApp({
  data() {
    return {
      greeting: '',
    };
  },
  computed: {
    greeting() {
      if (this.user.isAuthorised()) {
        this.greeting = 'Welcome back ' + this.user.username;
      }
    },
  },
});

// html
<p>{{ greeting }}</p>;
```

## Watchers

A more generic way to react to changes is to use watchers. E.g. a user has a property sum. If the sum of the items exceeds 5.000 than he gets 10% sale.

```js
// for loop
<button type="text" v-on:click="buy(item.price)">Buy</button>
// end loop
<p>Sum: {{ sum }} </p>

// app.js
const app = Vue.createApp({
    data(){
        return {
            sum: 0
        }
    },
    methods: {
        buy(price) {
           this.sum += price;
        }
    },
    watch:{
        sum(value){
            if (sum > 5000){
                this.sum = value * 0.9;
            }
        }
    }
});

```

## When to use methods, computed or watch

**Methods:** primarly for event-binding v-on.click="doSmthing()" . Also for data binding {{ sum() }}, but it can cause side-effects, see "Computed Properties"

**Computed:** can only be used with data binding {{ sum }}. It should be used, when a property depends on other properties or data.

**Watch:** when we want to execute a code in reaction to some changed data.
