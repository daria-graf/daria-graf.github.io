# Special folders

| Command   | Description                                                                                                                                                                 |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `_drafts` | The names of the files don't have to start with the date as the files inside the '\_posts' folder in order to be displayed when running the `jekyll serve --draft` command. |

# Commands

`jekyll serve` or `jekyll s` build the site and serve it. Make sure that you are in the correct folder, before running the command, if not no index.html will be generated.

`jekyll serve --draft` makes the files from the draft folder visible and accessible under the blog posts

# Stop the jekyll server

`CTRL + C` stops the server properly

When you get the error like `Address already in use - bind(2) for 127.0.0.1:4000 (Errno::EADDRINUSE)` you can stop the process by finding the PID with `ps aux | grep jekyll` and then explicitly kill the process by using the `kill -9 <PID>`command.

# Installing jekyll

In order to install `jekyll`, you should have `ruby` installed on your computer. The best way to do it on Mac
is to use `brew install chruby ruby-install`. There is a nice [step-by-step instruction by Moncef Belyamani](https://www.moncefbelyamani.com/how-to-install-xcode-homebrew-git-rvm-ruby-on-mac/) how to do it. For my Mac Version 10.15.7 it was really a problem, so I had to do `brew install ruby`.

If `ruby -v` still shows an old version than you need to add the following line:

```bash
export PATH=/usr/local/opt/ruby/bin:$PATH
```

to your `~/.zshrc` file.

# Use Images

In order to use images on your pages, you should create a `assets` folder.
I have created for example a `assets/img/` folder for my images.
Next time you build your website, jekyll automatically copies your assets into the `_site/assets` folder.

In the blog post itself you can use display an image by using

```bash
![Image description](/assets/img/some_image.jpg "Description of the image on hover")
```

# Use permalink

In order to display a particular URL to an article a `permalink` attribute can be used in the front matter section:

```bash
permalink: report-on-informatiktage-2015
```
