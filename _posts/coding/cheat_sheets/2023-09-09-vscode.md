# Navigating in VSCode

View: Extensions command - `⇧⌘X`

Command Palette - `⇧⌘P`

Quick Open, Go to File - `⌘P`

New window/instance - `⇧⌘N`

Replace - `⌥⌘F`

# Working with the Code

Select current line - `⌘L`

Go to line - `⌃G`

Add line comment - `⌘K, then ⌘C`

Remove line comment - `⌘K ⌘U`

Format document - `⇧⌥F`

Format selection - `⌘K, then ⌘F`

Quick Fix - `⌘.`

Show References - `⇧F12`

Trigger suggestion - `^Space`

Trigger parameter hints - `⇧⌘Space`

Go to Definition - `F12`

Peek Definition - `⌥F12`
