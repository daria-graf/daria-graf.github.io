# Installation

Install local mongodb version

```bash
brew install mongodb-community@4.2
```

For more instructions see [Install mongodb on macOS (external link)](https://docs.mongodb.com/manual/tutorial/install-mongodb-on-os-x/)

# Commands

`brew services start mongodb-community@4.2` run mongoDB as a service

`brew services stop mongodb-community@4.2` stop mongoDB

`mongo` connect to use mongodb

# Working with Documents

Insert a single Document

```bash
db.<collectionName>.insertOne(
   { item: "canvas", qty: 100, tags: ["cotton"], size: { h: 28, w: 35.5, uom: "cm" } }
)
```

`db.getCollectionNames()` list all existing Collections
