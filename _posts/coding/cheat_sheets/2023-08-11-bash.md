Shell - это обычная программа, которая выполняет команды, заданные в текстовом терминале (promt)
Существуют различные shell, многие из них имеют много общего друг с другом. Здесь будет рассмотрен bash (Bourne Again Shell)
[На этом сайте](https://natelandau.com/my-mac-osx-bash_profile/) можно посмотреть, как настроить свой bash на MacOS.
Так же другой [полезный линк](http://www.yolinux.com/TUTORIALS/Subversion.html)
shell prompt = command line - это текстовый терминал, который позволяет манипулировать данными и файлами, читать и писать/сохранять файлы, а также запускать программы

Команды создают процессы, которые могут выполняться на "переднем" плане (последующие выполнение команд возможно только после окончания текущего процесса) или "заднем" плане (работают параллельно с остальными процессами, пр. batch processes, Daemons)

Команды имееют форму: `имя_программы -опции файл`
Пример: $ wc -l text.txt

# Общая информация:

Стандартный ввод данных -> клавиатура
Стандартный вывод данных -> монитор (стандартные ошибки выводятся, к примеру, всегда на мониторе)

# Основные команды:

`man` (Manual page): получить онлайн-документацию по команде. Форма: `man имя_программы`

`man ls` вывод информация о "ls" на дисплей

`man -k [слово_для_поиска]` поиск в Manual pages по заданному слову

## Работа с каталогами

`pwd` показать, в каком каталоге мы сейчас находимся

`ls` отобразить список файлов и каталогов/папок в текущей категории

`ls -a` отобразить список файлов включая скрытые файлыб как .bash

`ls /bin` отобразить, что находится в каталоге /bin

`cd` перейти в "домашний" каталог

`cd /home` перейти в каталог /home

`cd ..` перейти на один каталог выше

`mkdir dir1 dir2` создать каталог dir1 и dir2 в текущем каталоге

`mkdir -p /odin/dva` создать каталог /odin и в нем каталог /odin/dva, если таких еще не существует

`mkdir -m 0755 katalog` создание каталога katalog с определенным правом доступа

`rmdir dir1 dir2` удаление каталогов dir1 и dir2, если в них ничего нет

`rmdir -r dir1` удаление каталога dir1, включая всех каталогов и файлов, которые он содержит

`rmdir -p /odin/dva/tree` удаление каталогов /odin/dva/tree, /odin/dva и /odin

`cp -r dir1/ dir2/` скопировать каталог dir в каталог dir2

## Работа с файлами

`diff -u test1.txt test2.txt` сравнение содержимого двух файлов

`curl www.here_is_a_link.com/some_file.html > file.html` скачать файл под именем file.html в текущую директорию

`mv ~/Downloads/*.JPG ~/Downloads/images/` все файлы с расширение .jpg переместить в home_directory/Downloads/images/

## Работа с usb носителями

`sudo fdisk -l` показать доступные носители

`sudo mkdir /media/usb` создаем папку, куда будет монтироваться содержание usb

`sudo mount /dev/sdb1 /media/usb` монтируем содердание usb, теперь можно видеть содержание папки

`sudo umount /media/usb` демонтация содержание usb

## Работа с редактором VIM

При входе в vim, мы оказваемся в command mode (переход с помощью `Esc` и `:` для ввода команд),
чтобы переключиться в insert mode необходимо нажать `i` на клавиатуре.
Также смотри [ссылку](http://tldp.org/LDP/intro-linux/html/sect_06_02.html)

`vim [файл]` создать файл и открыть в редакторе vim

`:w` сохранить текущий файл

`:x` или `:wq!` или двойное нажатие `Shift+Z`сохранить текущий файл и выйти из vim

`:q!` выйти из vim без изменений

[Дополнительная информация](http://www.tldp.org/LDP/intro-linux/html/intro_03.html)

## Архив данных

`zip -er newZipArchive.zip fileToZip.txt` - создать архив с паролем
`zip -r function.zip .`- запаковать текущую папку в архив и включить в него все файлы из текущей папки/директории

## Работа с процессами

`sudo lsof -t -i tcp:4200 | xargs kill -9` - завершить процесс, который использует порт tcp:4200

When you get the error like `Address already in use - bind(2) for 127.0.0.1:4000 (Errno::EADDRINUSE)` you can stop the process by finding the PID with `ps aux | grep jekyll` and then explicitly kill the process by using the `kill -9 <PID>`command.

## Локальная настройка bash/zshrc(MacOS)
Глобальные локальные настройки bash/zshrc храняться в домашнем каталоге в файле `~/.bash` или `~/.zshrc`соотвественно.
После того, как настройки были изменены и были сразу же запущены, можно закрыть и открыть терминал либо запустить команду `source ~/.zshrc`

В файле можно также создать алиас для команд, например

```bash
#Node settings
export PATH="/usr/local/opt/node@18/bin:$PATH"

alias node16='export PATH="/usr/local/opt/node@16/bin:$PATH"'
alias node18='export PATH="/usr/local/opt/node@18/bin:$PATH"'
```
