# Working with a new or an existing project / Работа с существующим или новым проектом

`git clone https://example.com/repository.git` - создание локальной копии проекта

`git init` - создание нового хранилища в текущем каталоге

# Working directory / Рабочий каталог

`git add file.txt` - отправить файл в staging area

`git diff` - показать различие между файлами в working directory и staging area

`git status` - актуальный статус файлов в working directory и staging area

`git reset --hard` - (!Внимание) отменить все изменения в working directory и staging area

`git merge --abort` - Отменить все изменения в текущем ответвлении после неудачного слияния (merge) с большим кол-вом конфликтов, либо неудачного обноваления ветки (pull). Действует, если изменения не были опубликованы (commit).

`git clean -f` - delete untracked files

# Staging area / Переходная зона

`git commit -m "message"` - записать изменения в Repository

Смотри [http://udacity.github.io/git-styleguide/](Commit message style)

`git diff --staged` - показать различие между файлами в staging area и repository

# Repository (local) / Хранилище

`git diff [commit_old] [commit_new]` - показать различия между двумя записями в Repository

`git log` - показать список всех изменений (от новых к старым), опубликованных в repository

`git checkout [commit]` - вернуть все файлов к определенной версии

# Branches / Ответвления

`git branch` - показать существующие ответвления

`git branch [name]` - создать новое ответвление

`git checkout -b [name]` - создать новое ответвление

# Revert Merge

```bash
git revert <Hash des Commits> -m 1
git push
```

# Revert Commit

```bash
git revert <Hash des Commits>
git push
```

# Cancel local unpushed commits (or merge)

```bash
git reset --hard
git reset --hard HEAD~1
// or
git reset --hard origin/dev
```

# Stashing

Stash local changes

```bash
git stash
git stash —include-untracked
```

`git stash pop` take and apply the topmost stash

# Cherry Pick:

Make sure you are on the branch you want to apply the commit to

`git checkout branch`

(Create a /cherry-pick branch from the main branch in order to create a pull-request later) - optional

```bash
git cherry-pick <commit-hash>
// If you cherry-pick from a public branch use „-x“
git cherry-pick -x <commit-hash>
git push
```

# Manage remote repo

`git remote set-url origin <https://myrepo.com/repo.git>`- set new remote repo

`git remote -v` - show current remote repository
